The extension can't use some sites yet

If nothing happened, allow it by hand: ⋮ → Add-ons → Open in Freedium → Permissions (on a computer: the extension's details page).

Bypass sites

The toolbar button opens a page through the first enabled site. Press it again on that page to switch to the next one.

    Floating button

    A button in the corner of the page that does the same as the toolbar button. Drag it to move it; its × hides it until the page is reloaded.

    Site addresses

    • {url} becomes the full article address, e.g. https://archive.ph/newest/{url}
    • {encoded} becomes the address percent-encoded, for sites that take it as a parameter, e.g. https://example.com/read?u={encoded}
    • {path} becomes only the path, e.g. https://scribe.rip/{path}
    • {domain} becomes the site's address the way Google Translate writes it (www-economist-com), e.g. https://{domain}.translate.goog/{path}

    When you save a site that's new, the browser asks for permission to see its pages, so the automatic fallback can tell when one fails and the floating button can appear on it.
